## Dogfile 2.2.1

- **Batch tools** is now one button on the Organize ribbon. It opens the Batch tools page, where Rename Studio and What is this? are listed with the other tools.
- Packaging fix for the Microsoft Store: Dogfile now ships with everything it needs built in, so it no longer depends on a separately installed Visual C++ runtime.
- Updated the website and the Store listing to show every feature.
