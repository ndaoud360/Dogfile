Folders, Previews and Documents in One Window

Tabs and Split Panes

Drag a tab to the edge of the window to split it.

  • Two panes free, three or four with Pro
  • Each tab keeps its own view, sort and scroll position
  • Workspaces save a layout of tabs and panes to reopen later
  • Drag a file from a folder onto Notepad, Office, 3D, PSD, Photos or the Player to open it there

See a File Before You Open It

Works for photos, PDFs, Office documents, video, audio, code and archives.

  • Space bar opens a full-size quick look
  • Rate, tag and add notes to any file
  • No extension, or the wrong one? What is this? looks inside the file and offers to fix the name

Office Documents, Built In

Word, Excel, PowerPoint and PDF files open in a tab and can be edited and saved. Microsoft Office doesn’t need to be installed.

  • Edit text, tables, cells and formulas
  • Present slides full screen

Macro Recorder

Do something once and Dogfile writes down the steps. Replay them with a click, a shortcut, on a schedule, or when new files land in a folder.

Every step can be edited, reordered or removed afterward.

Pro

Never Miss a Due Date

Dogfile finds the due or expiry date in your bills, contracts, warranties and IDs, then sends a Windows notification before the day comes.

Point it at a folder and new documents are picked up on their own. Nothing leaves your PC.

Want to be reminded about something else? Right-click any file or folder and choose Set a reminder.

Pro

Do the Same Thing to a Hundred Files

Select a pile of files, open Batch Tools and pick what to do. Dogfile shows what it will change before it changes anything.

  • Pictures. Make them smaller, change the type, compress, take off camera details or add your watermark.
  • Rename Studio. Find and replace, numbers, case, prefixes and suffixes, with a preview of every new name.
  • Folders and documents. Pack files into folders, flatten them, zip or extract each one, pull the text out of Word and PDF files, merge PDFs.
  • Careful by default. New files never replace existing ones, and Undo brings changes back.

Also in the box: dates and attributes, find and replace inside files, tags and notes, music tags, checksums, shortcuts and links, and vocals and instrumentals for a whole album.
